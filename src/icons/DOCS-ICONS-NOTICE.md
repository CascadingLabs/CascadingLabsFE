# Documentation switch icons

Rust, Python and uv use unchanged monochrome Simple Icons SVGs (CC0):

- https://github.com/simple-icons/simple-icons/blob/develop/icons/rust.svg
- https://github.com/simple-icons/simple-icons/blob/develop/icons/python.svg
- https://github.com/simple-icons/simple-icons/blob/develop/icons/uv.svg
- https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md

Cargo uses the Phosphor package glyph, rather than a brand logo:

- https://github.com/phosphor-icons/core/blob/main/assets/regular/package.svg
- See PHOSPHOR-LICENSE for the MIT license.

All icons render as CSS masks in the current control color for light and dark themes.
