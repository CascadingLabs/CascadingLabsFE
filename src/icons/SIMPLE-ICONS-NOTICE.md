The Rust and Python language SVGs are unchanged monochrome logos from Simple Icons.

- Rust: https://github.com/simple-icons/simple-icons/blob/develop/icons/rust.svg
- Python: https://github.com/simple-icons/simple-icons/blob/develop/icons/python.svg
- Upstream license: https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md

The sidebar displays these SVGs as monochrome CSS masks in the current text color.
